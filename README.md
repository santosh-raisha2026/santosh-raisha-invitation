# Santosh & Raisha — Engagement Invitation

An interactive, bilingual invitation for 12 October 2026 at 3:00 PM, Surya Events.

## Publish with GitHub Pages

1. Sign in to GitHub as `rejanbala-cell` and create a public repository called `santosh-raisha-invitation`. Turn **Add README** on.
2. Extract this ZIP. Open your repository, select **Add file → Upload files**, and drag in the extracted contents, including the entire `assets` folder. `index.html` must be directly at the repository root, alongside `styles.css` and `app.js`. Upload the extracted files, not this ZIP or an outer folder. Commit the changes to `main`.
3. Open **Settings → Pages**. Set **Source** to **Deploy from a branch**, **Branch** to `main`, and folder to **/(root)**. Select **Save**.
4. GitHub can take up to 10 minutes to publish. Get the confirmed public URL from **Settings → Pages → Visit site**. With the account and repository name above, the expected URL is `https://rejanbala-cell.github.io/santosh-raisha-invitation/`.

GitHub Pages has no scheduled expiry documented for a published site; keep the repository, account, and Pages publishing available. This is not a lifetime availability guarantee.

Official instructions:
- https://docs.github.com/en/pages/quickstart
- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
- https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository

## Local preview

Open `index.html` in a browser. Select **Open invitation** to enter and start the gentle background music. Use the music button to pause it. All photos, music, and fonts are included locally. No build command, package installation, or API key is needed.

## Event details

The countdown uses `2026-10-12T15:00:00+05:45`, so it reaches zero at the correct Nepal local time wherever a guest opens the invitation. The timezone abbreviation is hidden from the invitation. Directions open the supplied Google Maps link.

The wording uses `इन्गेजमेन्ट` and the corrected name `रैसा`. The opening photo is circular; the main portrait has an arched frame and original colors.
